Before calling this tool, write the complete plan in the assistant response so it remains visible above the review form. Pass the same plan in `plan`. Submitting it persists the plan and enters revision/review state.

Approval enters approved-plan execution with full implementation tools while keeping the plan-specific instruction profile active. Revision keeps the persisted plan and returns the user's feedback for improvement. Rejection stops the turn without permitting execution. This tool fails clearly outside plan drafting/revision or when the plan is empty.
