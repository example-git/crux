Fetch a URL or search the web using a sub-process that extracts, summarizes, and answers questions about the content. Slower and costlier than fetch; use fetch for raw content or API responses.

All page requests use recent Google Chrome navigation headers without a Crux or CLI user agent. Mode defaults to normal (anonymous). Use mode: user only when the user requests browser-authenticated access. This applies to the initial URL and every delegated web_fetch, including when no initial URL is supplied. Each user-mode page fetch requires explicit request or current-session consent to copy cookies from a selected browser profile. General tool approval does not grant browser access. If Cloudflare requires a browser check, Crux opens the challenged URL in the user's browser, waits for completion or cancellation, recopies cookies from the approved profile, and retries once. Denial, cancellation, or failure never falls back to anonymous fetching. Web searches remain anonymous. This is HTTP fetching with a user-completed challenge relay, not general browser automation or JavaScript execution; browser cookies are never written back.
