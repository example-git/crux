Fetch a URL or search the web using a sub-process that extracts, summarizes, and answers questions about the content. Slower and costlier than fetch; use fetch for raw content or API responses.

Mode defaults to normal (anonymous). Use mode: user only when the user requests browser-authenticated access. This applies to the initial URL and every delegated web_fetch, including when no initial URL is supplied. Each page fetch requires explicit request or current-session consent to copy cookies from a selected browser profile and use its matching user agent. General tool approval does not grant browser access. Denial or failure never falls back to anonymous fetching. Web searches remain anonymous. This is HTTP fetching, not browser automation or JavaScript execution; browser cookies are never written back.
